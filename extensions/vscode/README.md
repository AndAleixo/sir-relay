# Sir Relay

Sir Relay organizes your own work, or the work of a group. That work lives on [SRelay](https://app.sirrelay.com). This extension makes those tasks easier to manage: your column stays in the sidebar, and a change here is the same task on the site.

## Set up

1. Open the **SRelay** icon in the activity bar.
2. Choose **Sign in**. The site links this editor.
3. If the editor does not open, copy the code on the site and use **I have a code**.

A new code replaces the previous one.

## What you can do

- Switch group, when you belong to more than one.
- Add a task: title, assignee, project, difficulty, due date, description.
- Start the first to-do, move another up, or complete the one in progress.
- Edit a title. Escape cancels.
- Hide **Done**. It starts hidden.

## Settings

| Setting | Default | Meaning |
| --- | --- | --- |
| `sirrelay.url` | `https://app.sirrelay.com` | Origin of the SRelay app, with no path. |
